# Papers

The paper collection is organized into two groups:

- `traditional/`: classic recommendation papers
- `llmrec/`: recent LLM-based recommendation papers

Current naming rule:

- use lowercase
- use underscores instead of spaces
- keep names short and stable

Examples:

- `bpr.pdf`
- `ncf.pdf`
- `tagcf.pdf`
- `rlmrec.pdf`
